# BookStore API - .NET 8

REST API for managing a book store, built with .NET 8 and Entity Framework Core. Supports book, author, category, and user management with JWT authentication.

## Technologies

- .NET 8
- Entity Framework Core 8
- SQL Server (or any EF-supported database)
- JWT Authentication
- Swagger/OpenAPI
- AutoMapper
- FluentValidation
